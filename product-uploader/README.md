# כלי הקמת מוצר — אתר סחר ← באק אופיס

כלי שרץ **במחשב שלך** (בלי חסימות רשת). הוא שואב נתוני מוצר מאתר הסחר שלך,
מחיל את כללי ההקמה מהחוברת, ומכין/מקים את המוצר בבאק אופיס (`ashmoret-itu`).

## מה הוא עושה
1. **שואב** שם, מחיר, תיאור, תמונות ומק"ט מדף מוצר באתר הסחר.
2. **מנרמל** לפי הכללים:
   - 💰 **מחיר לא-עגול** — 1,500 → 1,499 (אוטומטי).
   - 📝 **תיאור** עם כל סעיפי החובה: שווי שוק, זמן אספקה, ביטול/החזרה, אחריות, שם החברה + טלפון שירות, איסוף עצמי, "התמונה להמחשה בלבד".
   - 🏷️ **מילות מפתח** מופרדות בפסיקים.
   - ⚠️ **אזהרה** אם חסר ספק סחורה (חובה לדוח הזמנות).
3. **מקים** בבאק אופיס דרך דפדפן אוטומטי (Playwright).

> 🖼️ תזכורת: התמונה הראשונה צריכה להיות **תמונת אווירה** (לא רקע לבן), בגודל **500×500 JPG**.

## התקנה (פעם אחת)
צריך [Node.js](https://nodejs.org) מגרסה 18 ומעלה.

```bash
cd product-uploader
npm install
npx playwright install chromium
cp config.example.json config.json   # ואז פתח את config.json ומלא פרטים
```

ב-`config.json` ממלאים את שם המשתמש והסיסמה לבאק אופיס, וברירות מחדל
(אחריות, טלפון שירות, מספר תשלומים) שחוזרות לכל מוצר.

## שימוש

```bash
# לראות מה נשאב ממוצר אחד:
node src/cli.js scrape "https://your-shop.co.il/product/123"

# שאיבה + הכנה מלאה לקובץ (מחיר לא-עגול, תיאור מורכב):
node src/cli.js prepare "https://your-shop.co.il/product/123"

# הרבה מוצרים בבת אחת (קובץ עם כתובת בכל שורה):
node src/cli.js batch urls.txt

# הקמה בבאק אופיס (ברירת מחדל: ריצה יבשה — מתחבר ומצלם, לא יוצר):
node src/cli.js upload data/product-123.json --show
```

דגלים: `--show` דפדפן גלוי · `--go` הקמה אמיתית (רק אחרי השלמת הבוררים).

## בדיקות

הלוגיקה העסקית (תמחור, תיאור, מילות מפתח) מכוסה בבדיקות אוטומטיות.

## מה עוד צריך כדי להשלים אוטומציה מלאה
השלד מוכן, אבל שני חלקים תלויים ב**מבנה האתרים האמיתי**, שעדיין לא נראה:

| חלק | מה צריך ממך |
|-----|-------------|
| שאיבה מדויקת מאתר הסחר | קישור לדף מוצר אחד (הכלי מנסה JSON-LD/OpenGraph אוטומטית; בוררים מותאמים רק אם צריך) |
| הקמה אוטומטית בבאק אופיס | ה-HTML או צילומי מסך של דף ההתחברות + מסכי "אחזקה ← הקמת מוצר" |

עד שהבוררים של הבאק אופיס יושלמו, `upload` רץ ב**מצב יבש**: מתחבר, מגיע למסך,
מצלם צילום מסך ל-`data/`, ולא יוצר מוצר — כדי לא להכניס נתונים שגויים.

```
test/               בדיקות אוטומטיות

```
